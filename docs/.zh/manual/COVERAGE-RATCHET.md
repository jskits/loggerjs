# 覆盖率棘轮

覆盖率阈值是防止回退的下限，而不是质量目标。只有在实测结果留出了足以容纳 V8 覆盖率正常波动的余量，并且新增测试验证的是有意义的行为而非实现细节时，才提高阈值。

阈值定义在 `vitest.coverage.config.ts` 中。重新生成快照：

```bash
pnpm test:coverage
```

## 棘轮规则

- 全局阈值至少比实测总值低两个百分点，除非有意收窄差距并在本页记录原因。
- 对已经有成熟覆盖率的高风险文件，优先设置文件级阈值，例如浏览器 HTTP 投递和 OTLP JSON 映射。
- 不要因为其他文件拉高了平均值，就提高仍有高风险分支未覆盖的包的阈值。
- 仅为覆盖率而写的测试也必须断言外部可观察的行为：错误、重试、过滤、导入边界、导出的文件名、生命周期清理或捕获的 payload 结构。
- 降低阈值必须在同一次变更中经过明确的质量评审。
